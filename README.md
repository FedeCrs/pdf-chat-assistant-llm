# 📄 PDF Chat Assistant (LLM)

AI assistant for interacting with PDF documents through natural language queries.

## 📌 Overview

This project allows users to upload and analyze PDF documents using an LLM-powered assistant.  
It is designed to make document exploration easier by enabling question-answering over PDF content in a simple interface.

## 🚀 Features

- Upload PDF documents
- Extract and process PDF text
- Ask natural language questions about the content
- Generate contextual answers with an LLM
- Simple user interaction through a lightweight interface

## 🛠️ Tech Stack

- Python
- Streamlit
- LLM integration
- PDF processing libraries

## 📂 Project Structure

- `app.py` → main application logic
- `web.py` → web interface / interaction layer
- `requirements.txt` → project dependencies

## 🎯 Goal

Make PDF documents easier to explore by combining document processing and AI-based question answering.
